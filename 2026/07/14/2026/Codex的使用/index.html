二、配置

2.1 手动配置

  1. 获取api：https://bw.gsykj.com/
  2. 创建api秘钥
  3. 复制秘钥登陆codex
  4. 点击使用秘钥 → 按 Win+R，输入 %userprofile%\.codex 打开配置目录 → 将相应信息配置到相应文件 → 退出重启 → 新建对话看能否正常使用

2.2 CC Switch配置

  • 下载：https://ccswitch.lovable.app/

  • 配置：

    • 打开路由总开关
    • 找到自己使用的桌面体
    • 添加新的配置
    • 填写相关信息，主要就是API Key和API 请求地址

  • 遇到的问题：loveapi 无法连通: Connection failed: errorsending request for url(https://api.loveapi.top/v1)无法建立连接(DNS/连接/TLS/超时)。请检査 base ur 与网络。

    • 原因：cc-switch启用的本地路由，和clash的代理冲突了
    • 解决：

      1. Clash的规则文件： 添加下面这几行

        # 强制 localhost 和 127.0.0.1 走直连模式（必须放在最靠前的位置）
- DOMAIN-SUFFIX,localhost,DIRECT
- IP-CIDR,127.0.0.0/8,DIRECT


      2. 将Clash的TUN模式打开并关闭系统代理
